## Why 1.0 is written out

The binary default for `guidance_scale` with `cot=off` is **1.01**, not 1.0
(`README.md`, `docs/suno-generation-controls.md` §D.2). At exactly 1.0 the runtime
bypasses CFG; at 1.01 it still runs the two-branch path with nearly identical
branches. So the "defaults" variant sets `1.0` explicitly to mean *CFG off*.
`lora_nar_scale` really does default to 1.0, and is written out for auditability.

Outputs land in separate run directories, so the same track names do not collide.

## Compare

Pair each arm with `abu01_v3_3285212580.wav` from the same variant. The two
variants are separate experiments: do not compare `defaults/a01` with
`orig/a03`. If the merged arms help at alpha 0.3/0.5 but the vocal suffers, the
next step is a narrower alpha (e.g. 0.2 or 0.4), not a lower runtime scale —
runtime scale weakens v3 and the donor together.
