# Fadhl Shaker scores

Extracted from `local_workspace/fadhl_shaker_selected_scores.zip` (SheetSage2
transcriptions, `melody_only: false`, so the ABC carries chord symbols).

- One file per song, named by ASCII slug; the Arabic title and the slug are
  mapped in `manifests/fadhl_shaker_instrumental_01.md`.
- 23 of the 24 shortlisted songs have a `score.abc`.
- `القصة وما فيها` is missing because SheetSage2 failed to export its ABC
  (`abc_error: "Measure 154 (beat rows 308-310): non-consecutive beat IDs
  [1, 2, 2]"`). Its other artifacts are still in the zip.
- The scores are used as-is; voice labels (`V: Vocal`, `V: Ins`) are not
  sanitised in round 01.
