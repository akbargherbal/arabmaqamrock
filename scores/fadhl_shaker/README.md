# Fadhl Shaker scores

Extracted from `local_workspace/fadhl_shaker_selected_scores.zip` (SheetSage2
transcriptions, `melody_only: false`, so the ABC carries chord symbols).

- One file per song, named by ASCII slug; the Arabic title and the slug are
  mapped in `manifests/fadhl_shaker_instrumental_01.md`.
- All 24 shortlisted songs have a `score.abc`; the last one was added in round 10.
- `القصة وما فيها` was initially missing because SheetSage2 failed to export its
  ABC (`abc_error: "Measure 154 (beat rows 308-310): non-consecutive beat IDs
  [1, 2, 2]"`). Its other artifacts remained in the zip. It was re-transcribed
  with `--full` in round 10 and saved as `al_qissa_wama_fiha.abc`.
- The scores are used as-is in round 01; voice labels (`V: Vocal`, `V: Ins`) are
  not sanitised there.
- Round 02 uses `scores/fadhl_shaker_instrumental/`, generated by
  `plumbing/instrumentalize_scores.py` with the official YuE2 Vocal → Ins
  instrumental conversion. See `manifests/fadhl_shaker_instrumental_02.md`.
