# Guides

Reusable, project-independent playbooks distilled from the work in this repo.

- [Fixing mispronunciations in AI music — a preservation-first field guide](fixing_ai_music_mispronunciations.md)
  — **v2.0 (2026-11-15)**: how to repair a wrong word without re-rendering the
  take. Export tokens at generation, G0 token check, one process, four seeds,
  unit selection, consonant-onset comps, verification, review and delivery.
  - **Reference run:** [`cases/002_abu01_ajdad/RUN3.md`](../../cases/002_abu01_ajdad/RUN3.md)
    — `مِلَّتِي` in the T4 CFG 1.5 take, 26 min machine / 39 min wall.
  - **Historical case:** `docs/happy_accidents/Baghdad_Moon/token_surgery/`
    — the learning run, not the workflow to copy.
- [Repair session runbook](repair_session_runbook.md)
  — **v1.0**: the operational procedure proven on RUN3: intake, G0, defect
  card, one-process batch, filter, comp, verify, listen, package.
