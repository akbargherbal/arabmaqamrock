Validation · pre-flight

Score kills ABC rule 01

An external score replaces the plan. abc_* is dead with cot=off and rejected alongside score or abc_file — an explicit error, not a silent ignore.

1.0 is off rule 02

guidance_scale=1.0 bypasses CFG. It is not a quiet setting. 1.5 and 2.0 are the first takes that switch it on, and the voice path runs twice.

One adapter, one source rule 03

Do not combine manifest lora_*_scale with LORA_AR_SCALE / LORA_NAR_SCALE environment variables. Two sources for one setting are refused.

The seed is not a save file rule 04

A seed reproduces a take only when every resolved setting matches. Move one fader and the path changes — same seed, different song.
